# Hiraya User Guide

## Foundation Shell

Open Hiraya once while online. A supported Chromium browser installs the small shell for later offline reloads. The shell creates no workspace or file data in this milestone.

If Hiraya reports that browser storage is unavailable, update or switch to a current Chromium browser and choose **Check again**.

## Not Available Yet

Files, folders, synchronization, settings, applications, sharing, publication, editors, viewers, and themes return only after their new durable architecture is complete.
