# Hiraya New Tab

This permission-free Chromium extension opens `https://hiraya.sh/` whenever a
new tab is created.

## Test locally

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable developer mode.
3. Choose **Load unpacked** and select this `extension` directory.
4. Open a new tab.

Chrome does not allow extensions to override the New Tab page in Incognito
windows.
